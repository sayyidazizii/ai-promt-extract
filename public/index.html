Mengapa Membuat 5 Gambar Proses Dulu?

Dengan menyiapkan 5 gambar proses milestone (0s, 8s, 16s, 24s, 32s), Anda memegang kontrol penuh atas bentuk transformasi fisik. Anda tidak perlu lagi menunggu video selesai untuk screenshot. Di Google Flow, 4 klip video bisa langsung di-generate sekaligus secara paralel!

1

Pilih Gambar Referensi Anda di Web Ini

Anda memiliki 2 cara:
• Cara Instan: Langsung klik Download Gambar pada masing-masing kartu di web ini (hasil ekstraksi video atau tombol Generate AI FLUX).
• Cara Custom: Copy prompt gambar dari masing-masing kartu, lalu generate sendiri di Midjourney v6.

2

Buat Klip 1 (00:00 - 00:08) di Google Flow

Buka flow.google. Masukkan Gambar 1 sebagai input + paste prompt Klip 1. Klik Generate (8 detik).

3

Buat Klip 2 (00:08 - 00:16) di Google Flow

Masukkan Gambar 2 sebagai input + paste prompt Klip 2. Klik Generate (8 detik).

4

Buat Klip 3 (00:16 - 00:24) di Google Flow

Masukkan Gambar 3 sebagai input + paste prompt Klip 3. Klik Generate (8 detik).

5

Buat Klip 4 (00:24 - 00:32) di Google Flow

Masukkan Gambar 4 sebagai input + paste prompt Klip 4. Kamera akan bergerak sinematik memperlihatkan hasil akhir megah Gambar 5!

6

Gabung di CapCut (32 Detik Video Utuh)

Tarik ke-4 klip ke CapCut secara berurutan. Potong sedikit (trim 0.1s) di sambungan, tambahkan sound effect ASMR alat/pahat dan musik viral. Video 32 detik siap tayang!
